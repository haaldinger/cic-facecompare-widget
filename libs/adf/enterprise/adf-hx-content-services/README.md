# @alfresco/adf-hx-content-services

## Documentation

Storybook helps to develop and share hard-to-reach states and edge cases without needing to run whole app that will help sales team to do a basic demo by providing the necessary documentation.

Run the following command to start storybook.

```bash
npm run nx:run-target -- adf-enterprise-adf-hx-content-services:storybook --skip-nx-cache=true 
```
